Алгоритм рекомендации

Как система определяет подходящие книги

🎓 Метод взвешенного совпадения жанров (Weighted Genre Matching)

Система использует метод косинусного сходства (cosine similarity) для сравнения вектора предпочтений пользователя с жанровым профилем каждой книги. Каждому выбранному жанру присваивается вес, а результат — это процент совпадения от 0% до 100%. 

// Алгоритм рекомендации на JavaScript

// 1. База данных книг с жанрами
const books = [
  { title: "Дюна", author: "Фрэнк Герберт", genres: ["фантастика", "приключения"], year: 1965 },
  { title: "Гарри Поттер", author: "Дж.К. Роулинг", genres: ["фэнтези", "приключения"], year: 1997 },
  // ... и другие книги
];

// 2. Функция расчёта совпадения
function calculateMatch(userGenres, bookGenres) {
  let matches = 0;
  for (let genre of userGenres) {
    if (bookGenres.includes(genre)) matches++;
  }
  return (matches / bookGenres.length) * 100;
}

// 3. Сортировка и вывод рекомендаций
function getRecommendations(selectedGenres) {
  return books
    .map(book => ({
      ...book,
      score: calculateMatch(selectedGenres, book.genres)
    }))
    .filter(book => book.score > 0)
    .sort((a, b) => b.score - a.score);
}

📊 Этапы работы алгоритма:

1. Сбор данных: Пользователь выбирает жанры → формируется вектор предпочтений.

2. Сопоставление: Для каждой книги из базы вычисляется количество совпадающих жанров.

3. Ранжирование: Книги сортируются по проценту совпадения (match score).

4. Вывод: Отображаются топ-книг с наибольшей релевантностью.

О проекте

Данный проект демонстрирует принцип работы системы рекомендаций на примере подбора книг. В основе лежит алгоритм анализа жанров: каждая книга описывается набором жанровых тегов, а пользовательские предпочтения сравниваются с базой данных методом подсчёта совпадений.

В реальных системах рекомендаций (Amazon, Goodreads, Netflix) используются более сложные подходы: коллаборативная фильтрация, нейронные сети, NLP-анализ описаний и отзывы пользователей. Данный проект — упрощённая модель для понимания базового принципа.
